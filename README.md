# Vértice Estrutural — site institucional

Site institucional responsivo em HTML, CSS e JavaScript puro.

## Como visualizar
Abra `index.html` em um navegador. Para publicar, envie a pasta inteira para um serviço de hospedagem estática (por exemplo, Netlify, Vercel ou GitHub Pages).

## Personalizações recomendadas antes de publicar

- Confirmar o perfil do Instagram: @vertice.strutural.
- Substituir imagens de referência por fotografias autorizadas de projetos executados pela empresa.

O site usa Google Fonts via internet; as fontes de sistema continuam disponíveis se estiver offline.
